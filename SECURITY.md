# Security Policy

This repository is an earlier development line. Security fixes are prioritised in [smashingapps-unified](https://github.com/InnovatingTech/smashingapps-unified).

Do not disclose suspected vulnerabilities, API keys or user data in a public issue. Use this repository's **Security** tab and **Report a vulnerability** option where available, or report against the current consolidated repository if the issue applies there. Reports are reviewed on a best-effort basis; this policy does not create a support SLA.
